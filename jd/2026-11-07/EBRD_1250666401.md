Platform Quality Engineer (Hybrid Infrastructure)

As an Associate, Quality Engineer, Platform Engineering, you’ll work across Azure, hybrid infrastructure, networking, Infrastructure as Code and DevOps to ensure our platforms are reliable, resilient, secure and production-ready.

This isn’t traditional application QA. You’ll test the platform itself, challenging how infrastructure behaves under load, during failure and through change. From Terraform deployments and Azure services to network performance, observability and recovery, you’ll work alongside Cloud, Infrastructure and DevOps engineers to identify risk early and build quality into the platform from the start.

What you’ll be doing

- Design and execute functional and non-functional testing across Azure and hybrid infrastructure.

- Independently validate Terraform/IaC deployments, configuration, drift, repeatability and CI/CD quality controls.

- Build automated tests and reusable validation checks using PowerShell, Python or Bash.

- Validate Azure services including AKS, API Management, networking, databases, RBAC and managed identities.

- Test performance, scalability, capacity, availability, resilience, failover and recovery.

- Perform network performance testing using iPerf or similar tools, assessing throughput, latency, jitter, packet loss and stability.

- Validate hybrid connectivity and network/storage paths including VPN, ExpressRoute, load balancing and private connectivity.

- Assess monitoring, logging, alerting and platform health indicators to ensure services are supportable in production.

- Investigate defects, support root-cause analysis and validate fixes.

- Define quality gates, acceptance criteria and test evidence, supporting Operational Acceptance Testing and production-readiness decisions.

- Work across Platform Engineering, Cloud, Infrastructure, Security and DevOps to embed quality throughout delivery.

What you’ll need

- Strong understanding of Azure and hybrid infrastructure, including networking, identity, operating systems, storage and cloud services.

- Practical experience testing Terraform or comparable Infrastructure as Code.

- Strong experience in non-functional testing, including performance, scalability, resilience, failover and recovery.

- Experience with risk-based testing, quality gates, acceptance criteria and production readiness.

- Good understanding of networking and experience testing performance across cloud or hybrid environments.

- Working knowledge of PowerShell, Python or Bash for test automation and validation.

- Understanding of CI/CD, observability, monitoring, logging and alerting.

- Experience with test design, defect management, Agile/DevOps delivery and technical risk reporting.

- Strong analytical, problem-solving and communication skills, with the confidence to challenge constructively.

Nice to have

- Kubernetes / AKS, Application Gateway, Traffic Manager, Azure Load Balancer, private endpoints or ExpressRoute.

- Chaos engineering or controlled failure testing.

- Azure Monitor, Log Analytics, Prometheus or OpenTelemetry.

- Experience with Platform Engineering or SRE environments.

- Knowledge of Zero Trust, network isolation and Key Vault.

- Understanding of server hardware, firmware and OS-level configuration.

- ISTQB CTFL or equivalent testing certification.

- AZ-900, AZ-104 or another relevant Azure certification.

- Exposure to AI infrastructure and AI-assisted testing, including GitHub Copilot and GitHub-based workflows.

Why you’ll love this role

- Work hands-on with Azure, Terraform, networking, Kubernetes, automation and DevOps.

- Go beyond traditional testing by exploring performance, failure, resilience and recovery.

- Use automation to make quality faster, repeatable and embedded into engineering delivery.

- Influence whether new platform capabilities are genuinely ready for production.

- Collaborate with specialists across Platform Engineering, Cloud, Infrastructure, Security and DevOps.

- Grow your expertise at the intersection of Quality Engineering, cloud and modern platform engineering.
