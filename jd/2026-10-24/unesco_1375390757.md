OVERVIEW

Core Planner, Core Manager, Core Data Portal, Core HR + are recently deployed, organization-wide platforms supporting UNESCO's programme planning, implementation, HR management, monitoring, reporting processes. They continue to evolve through UNESCO’s successive C/5 planning, implementation and reporting cycles. User guidance must therefore be maintained and updated after each major release and each new functionality. An extensive, functionally indexed user support library is available on the UNESCO Intranet and is routinely consulted by users before they contact the Service Desk, thereby preventing avoidable Level 1 tickets. The same methodology was applied in 2026 to support the launch of Core HR+.

With a growing pipeline of UNESCO80 initiatives, automation, AI and new digital solutions, DBS wishes to turn this capability into a DBS-wide function for user adoption and digital knowledge management. A key part of this evolution is preparing the DBS knowledge base for AI-enabled user support, a prerequisite for the AI agent pilot planned for 2027.

ASSIGNMENTS

To maintain and extend user documentation, launch communications and adoption support for DBS enterprise platforms, and to evolve this work into a standardized DBS-wide practice, while preparing an AI-ready knowledge base. The intended progression is: manual documentation → structured enterprise knowledge → AI-ready knowledge base → AI self-service → progressively reduced manual support demand.

A. User documentation and adoption (core)

- Maintain and update the user support library for Core Planner, Core Manager, Core Data Portal and Core HR+ following each release.

- Develop new guidance for new functionality, including new reporting capabilities and advanced reports, in time for the C/5 cycles falling within the contract period.

- Prepare launch communications and in-application guidance associated with new releases, acting as the link between technical delivery and business adoption.

- Provide back-up Level 1 support during absence, peak demand and critical business cycles.

B. DBS-wide user adoption and knowledge management (evolution)

- Apply the established methodology to other DBS projects, as prioritized by DBS

- Develop standardized, reusable documentation templates, launch communication guidelines and adoption practices for new IT projects.

- Document the approach so that it can be sustained and reused after the assignment.

C. AI-readiness of the knowledge base (key evolution)

- Continue converting legacy documentation into AI-readable formats and develop new material according to AI-readiness criteria.

- Curate and structure the DBS knowledge base, using recurring Level 1 questions identified by the Level 1 support consultant to set priorities.

- Prepare and quality-check the content required for the AI agent pilot and, where it is under way within the contract period, support validation of AI-generated responses and work closely with technical teams.
